# Пакет для NotebookLM (если прямое подключение недоступно)

## Источники для импорта
- [S001] Название, локальный PDF или URL; имеет ли пользователь право на загрузку.

## Действия пользователя
1. Авторизуйтесь в NotebookLM в собственном браузере.
2. Создайте новый блокнот с названием исследования.
3. Добавьте разрешённые источники.
4. Скопируйте нижеуказанные запросы и сохраните ответы с отсылками к источникам.
5. Предоставьте ответы/экспорт для завершения перекрёстной проверки.

## Запросы
- По каждому материалу: проблема, цель, дизайн, выборка, результаты, ограничения. Подтвердить конкретным фрагментом.
- Какие источники противоречат друг другу по полученным результатам и почему?
- Какие причинные выводы невозможны на основе этих дизайнов?
- Какие факты отсутствуют и требуют чтения полного текста?
